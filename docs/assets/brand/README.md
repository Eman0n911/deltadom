# DeltaDOM README visual assets

The illustrations express record identity through a blue ticket, a triangular mark,
and a cursor tether. Moving surrounding tickets express changing positions. Replacing
the identity breaks the tether and pauses input. These are illustrative assets, not
recordings of the product or independent efficacy evidence.

## Files

- `identity-thread.png`: original editorial illustration generated using the built-in
  imagegen tool. The exact prompt is in `illustration-prompt.txt`. The source image was
  copied into this repository without modification.
- `identity-motion.gif`: original 9-second looping motion illustration, 960 × 480;
  authored as code, not generated by editing the bitmap illustration. No outside images
  or competitor graphics are included. The opening frame is meaningful on its own.
- `identity-motion-still.png`: static alternative for readers who prefer no animation.
- `identity-motion-paused.png`: second keyframe for review.

Rebuild the animation using Python with Pillow:

```sh
python scripts/render_identity_motion.py
```
