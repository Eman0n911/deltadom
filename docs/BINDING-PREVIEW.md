# 点击身份检查 · 私密预览版

页面上有许多相同的“完成”“删除”“收藏”按钮时，记录位置可能不够：列表会排序，页面也可能在鼠标经过时换掉那一行。这个预览版记住按钮属于哪条记录，并在真正点击时再次核对。

这不是自主完成任意任务的 AI，也不是完整的流程录制器。目前一次保存、重放一个点击目标。它不需要模型账号、API Key 或 Rust 编译器。

## 第一次使用

适用：Apple 芯片 Mac、Google Chrome，以及 Python 3.12+ 或 uv。

1. 解压体验包。
2. 双击 **Start DeltaDOM.command**。
3. 观看四种实际浏览器行为：正常点击、普通定位器在行被替换后点错、身份防护阻止同一变化、重新排序后仍点击原记录。

首次安装会联网下载预编译依赖；演示只使用自带页面。没有独立应用签名或公证。若系统阻止脚本启动，可在解压目录的终端执行：

```sh
python3 install.py --demo binding-demo
```

这是机制演示，不是 Browser Use 的完整任务对比。演示结果和截图保存在 `deltadom-output/`。原本的观察录制演示仍可用 `python3 run.py demo` 打开。

## 保存一个目标

```sh
python3 run.py bind https://你的网页地址 --output action.json
```

打开的是独立浏览器，不读取日常浏览器的登录状态。可以正常点击、登录、打开目标页面；然后按住 **Option/Alt** 点击要保存的按钮。选取时会阻止这次输入继续传给页面。成功保存后浏览器关闭；不会保存之前的浏览步骤。

## 执行一次点击

```sh
python3 run.py bound-click action.json
```

需要手动登录的页面：

```sh
python3 run.py bound-click action.json --wait-for-login
```

这会执行一次真实点击，并保留浏览器供你核对；回到终端按回车后关闭。找不到原记录、身份不再唯一或点击期间记录改变时会停止，不会自动重试。默认显示中文结果。需要完整回执时可加 `--json`；其中 `clicked` 仅表示受检输入已发出，不表示服务器业务已成功。其余状态都需要检查页面，不能据此重复提交。

## 哪些情况尚不支持

- 页面网址必须与保存时完全一致；不自动替换查询参数或记录身份。
- 当前识别顶层页面的常见控件；不涵盖 iframe、封闭 shadow DOM、canvas。
- 优先使用可见记录链接；没有链接时保留区分记录的文字。金额、状态等文字变化可能导致拒绝。
- 页面处理函数内部先产生副作用，或者外观完全不变却执行另一项业务，不能靠可见身份检查阻止。
- `action.json` 可能含页面地址和记录名称，分享前请检查。

本预览仅供私密验证，未重新发布到 GitHub。完整对比与反例见仓库的 `benchmarks/BINDING-V9-RESULTS.md`。
